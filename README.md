## 二、各模块待办事项清单与内部协商建议（由成员自行认领决定）

> **说明**：以下仅列出各模块包含的具体工作项及常见配合建议，**不预设双人组内部的具体人选绑定**，由各组同学根据自身时间与擅长方向自行商议决定。

### 1. 竞赛文档与主文档辅写（张旭鹏，与魏奕超协同）
- **竞赛表格填写**：将团队信息与主文档项目内容填入《作品申报书（附件 1）》及《参赛作品汇总表（附件 2）》，跟进签字与盖章流程。
- **主文档辅助写作（可与魏奕超商定认领范围）**：建议可协助整理相对独立的章节素材，交由魏奕超统一合稿。

### 2. 主项目文档撰写（魏奕超，与张旭鹏协同）
- **研制报告主笔与统稿**：把控《校赛研制报告》整体结构、核心技术方案阐述（硬件前端、同步采样、信号处理、特征与判别、设计验证）及全文逻辑串联。
- **图文合拢**：接收作图组输出的最终配图并嵌入报告，确保正文叙述与图表内容一致。

### 3. PPT 制作组（方浩宇、刘畅，内部自行商定拆法）
- **核心任务**：基于主项目文档完成演示文稿的版式设计、内容提炼、图表排版与备注整理。
- **可选拆分建议（供两人商议二选一）**：
  - *建议方式 A（按前后章节拆分）*：一人先确定统一母版与配色，随后一人负责前半部分（背景痛点、问题边界、竞品对比、硬件与采样架构），另一人负责后半部分（特征与差分算法、仿真结果、可复核看板、验证计划与总结），最后合并微调。
  - *建议方式 B（按“内容提炼 + 视觉排版”拆分）*：一人负责从主报告中提炼每页的核心结论句、精简文字与表格数据，另一人负责页面视觉布局、卡片美化与图表对齐。

### 4. 作图与文档/PPT 校验组（郑月乐、王建旺，内部自行商定拆法）
- **核心任务一（项目作图）**：绘制与美化报告及 PPT 所需配图（包括：系统整体架构图、STM32 采样与滑窗状态机图、硬件调理电路/接线示意图、算法仿真对比曲线图、树莓派 Web 看板界面图等）。
- **核心任务二（PPT 与文档校验）**：对《申报书》《汇总表》《主项目文档》《PPT》进行质量把关与纠错。
- **可选拆分建议（供两人商议认领）**：
  - *作图拆分建议*：可按**“框图/硬件图（Draw.io / EDA 类）”**与**“数据曲线/界面图（Python / 网页截图类）”**分别认领，或按各自熟悉的工作流程和绘图工具自由分配。
  - *校验拆分建议*：一人侧重查**“跨文档数字与核心参数一致性”**（核对申报书、汇总表、报告、PPT 四处的名称、成本、技术参数是否完全一致），另一人侧重查**“公式符号、图表编号连续性、错别字与排版格式”**；也可两人分别通读全文后汇总修改意见。

## 零、 一页纸速览

* **一句话定义**〔计划〕：DORM-NILM-T1 是安装在单宿舍独立支路上的用电事件辨识终端。它用一路隔离电压采样和一只开口式电流互感器，在**指定设备与工作模式**内对启停事件输出“疑似标签＋未校准匹配分＋质量状态＋测量依据”；无法确定时输出“未知”，不自动断电。
* **校赛交付**〔计划〕：研制报告（D2）、架构图（D3）、处理流程图（D4）、设计核算与风险分析（D5）、答辩 PPT（D6）、逐字问答稿（D7）、盖章申报书（D1）。校赛不要求硬件实测；软件自检为可选加分项，未完成则标计划。
* **省赛前最低交付**〔计划〕：在批准的实验环境中打通“同步采样→事件检测→指定设备基线辨识→未知拒识→本地记录与 Web 展示”，并报告工况、失败案例与原始计数。谐波、调压、暂态分项验收，不捆绑承诺。
* **明确不做什么**：不自动切断市电；不做原生 App；不做楼层总进线；不承诺所有品牌型号；不凭电气特征判定“违规”或“火灾风险”；不宣称“国内首创”或“$100\%$ 识别”。
* **校赛凭什么可信**〔核算〕：把“测得到什么、测不到什么”拆成可复算的量。$3.30\text{ V}$、12 位、$50\text{ mV/A}$ 下，$0.1\text{ A}_{\text{rms}}$ 只剩约 $6.2$ 个 rms 码——这提示小信号风险，但**不能**反推“$40\text{ W}$ 以下不可识别、$100\text{ W}$ 以上可靠”，本版因此取消统一能力下限；两级 RC 实算 $956\text{ Hz}$、$350\text{ Hz}$ 处 $-0.49\text{ dB}$，只说明通带损失小，不说明阻带足够；`SCT013-020` 只有 $50/60\text{ Hz}$ 指标，谐波能否用到 7 次由 E1 决定，未通过不进在线分类。
* **40 秒陈述**：单一总功率阈值只说得出“用了多少电”，说不出“接进来的是什么”。部分商业产品已有恶性负载识别，我们的补位不是“别人只会看功率”，而是在单宿舍支路上为指定负载的启停提供可复核记录：前后功率、质量状态、有限阶谐波与缩略波形，并允许输出“未知”。先建低维基线，再检验谐波与暂态是否真的改善易混淆场景；校赛交设计核算与验证方案，省赛前用原型和数据说话。

## 第一部分 为什么是这件事

### 1.1 研究动机：按证据分级，而不是一条“严密因果链”

1. **〔已知事实〕宿舍电气安全值得关注，但定量口径未核实。** 人员密集、可燃物多、夜间易无人看管，违规大功率发热电器功率密度高，这是定性机制。公开报道常见“高校宿舍火灾电气原因占比过半”，但仅见二三手转述，未拿到消防部门原始统计口径；**正文不写起数与百分比**。
2. **〔合理假设〕单一总功率阈值有两类副作用。** 多台合规学习设备同时运行可能触及阈值，正常用电被误切断；部分学生可能用移相调压或半波整流插座把 $1000\text{ W}$ 水壶压到 $300\sim400\text{ W}$。但“限电必然导致违规”“调压后完全看不见”都不是已证因果：降到多少取决于负载与控制方式，低于阈值不等于不可见。
3. **〔核查与实验计划〕** 补齐本校用电规则、可追溯的限电报道原文、具体商业型号手册；在授权实验中测试调压负载与正常非线性负载（主动 PFC、调速电机、调光器）能否区分。降低有功是物理现象，火灾风险还取决于器件质量、接线与散热，**不能由功率降低直接推导**。

### 1.2 数据可信度分级

| 级别 | 判定标准 | 使用规则 | 当前归类 |
| :---: | :--- | :--- | :--- |
| **A** | 已取得原文，记录版本、页码与所支持的具体结论 | 仅已核实的对应结论可引用，不搭便车 | ST 手册/RM0008、YHDC 手册、CMSIS 版本文档、PLAID/WHITED 说明、`GB 17625.1-2022`；实际电压模块与实装运放手册待取得后登记 |
| **B** | 有权威媒体报道，未拿到原始统计 | 写“据公开报道”，标“申报前复核” | 2025 年 12 月高校限电争议 |
| **C** | 仅网文转述或商业报告摘要 | **不进正文**，只列 13.1 待核 | 火灾起数与占比、NILM 市场规模、行业毛利率 |

> A 级不是“资料类别”，而是“资料—结论”的对应关系：`LM358` 手册支持压摆率典型值，不支持板级摆幅保证；互感器裸件手册不支持成品模块隔离结论。

### 1.3 选题目的

让宿舍用电管理从只知“用了多少电”，走向看清“接入的是什么类型电器”，且每条判断都带可复核的测量依据与质量状态。

### 1.4 价值逻辑与边界

* **对后勤**〔假设，需访谈〕：为支路异常用电核查**提供线索**，不直接认定违规。记录展示实测功率变化、质量、疑似类别与波形依据；不能推断学生身份，也不能从调压后的功率反推额定功率。减少投诉、提高效率需另做用户研究。
* **对节能服务商**〔假设，需市场验证〕：分项计量是改造入口，逐插孔改装成本高、抵触大；单支路终端在负载有限的宿舍场景有可迁移潜力，但商业价值取决于许可、误报成本与运维，本方案不测算。
* **不夸大的边界**：不宣称消灭火灾或打开多大规模市场；当前可验证的工程价值是“把靠人工巡查发现的用电行为，转成一条低成本、可留痕、可复核的本地事件记录”。

### 1.5 NILM 的三个物理难点

1. **叠加病态性**：支路总电流是各电器电流的相量和，多台同开时总谐波不属于任何单台设备。
2. **类内差异大**：同是电吹风，全波/半波档、不同品牌差异极大；同一设备在不同阶段特性也漂移。
3. **背景漂移污染差分**：游戏本、变频设备的功率波动会污染“事件后减事件前”。

应对不是“彻底解决”，而是**场景约束＋状态机降级**：只测单宿舍支路、只抓离散启停、把“背景过大”“多重事件”“未知负载”做成显式分支。降级不等于可靠——背景不稳时标量与暂态也可能失效，此时只记录、不分类（见 6.4）。

## 第二部分 问题界定：只做哪一段

### 2.1 最小验证场景：单宿舍独立支路

〔事实〕典型拓扑为楼层总进线→各房间独立支路（$10\text{ A}$ 或 $16\text{ A}$ 空开）。只取单间支路，理由有三：

1. **〔假设〕可分解性**：相对楼层总进线，单支路设备更少，预期减少背景叠加；实际改善由组合实验评估，**不预填“信噪比高一个数量级”**。
2. **可归属性**：传感器装在支路空开下口，事件天然归属该房间，无需跨房间推断人员。
3. **可实施性**：卡扣式 CT 与采样盒通常可纳入配电箱或门口暗盒，无需穿墙凿线。〔假设〕需现场勘查与后勤许可。**被测回路边界必须先查清**：照明、空调、备用插座是否同支路，决定“单点覆盖”能否成立。

### 2.2 第一阶段交付形态

**DORM-NILM-T1** 由三个模块组成：

* **隔离测量单元**〔计划〕：`SCT013-020` 候选 CT（$1.65\text{ V}$ 名义偏置）＋**经审核的隔离电压方案**。先取得实际模块资料，再确定供电、摆幅与 ADC 接口；不以“调电位器”替代安全设计。
* **边缘特征单元**〔计划〕：F103ZE 以定时器触发双 ADC＋DMA 完成均匀采样、事件检测与**已验证的低维特征**；谐波在通过自检与标定后启用；MCU 不跑首版分类器。
* **本地记录与分类单元**〔计划〕：树莓派或 PC 按明确的特征版本完成分类、拒识、落库与局域网 Web（事件时间轴＋详情卡：疑似标签、未校准匹配分、质量、前后功率、可用阶次谐波、缩略波形）。

> **核心动作**：只做“记录事件”与“给出可复核依据”，不做继电器断电。若用预置 JSON 驱动 Web 回放，界面必须标“界面示意，非实验结果”。

### 2.3 五项不承诺

1. **不承诺品牌型号通用识别**：范围由指定设备与工作模式验证确定；可辅助标注阻性、整流、电机、移相等属性，但**不构成互斥完整分类**；物理不可分的器具合并或拒识，规则由实验定。
2. **不凭电气特征判定“违规”或“火灾风险”**：输出限定为“疑似类别＋未校准匹配分＋依据＋质量”。
3. **不承诺全面优于商业电表**：只对准确型号的公开功能逐项对照，不贬低未公开指标。
4. **不承诺自动精准切断单个电器**：插座并联，支路开关无法只切热得快；第一代不装执行器。
5. **不填未经实测的准确率、召回率、误报率**：校赛一律留空标〔待测〕。

### 2.4 三个概念必须分开

| 概念 | 含义 | 系统输出边界 |
| :--- | :--- | :--- |
| **负载类别识别** | 在已验证范围内辨识事件并描述物理属性 | **核心目标**：疑似标签＋未校准匹配分＋质量＋依据；允许“未知” |
| **违规行为认定** | 是否违反校规 | **不直接定性**：由宿管结合证据与校规人工复核 |
| **火灾风险评估** | 是否过载、过热、构成起火危险 | **不直接判定**：只提供功率、畸变、持续时长等线索 |

### 2.5 并联拓扑决定“不能在支路级只切一个电器”

〔事实与现场待核〕同一被测支路内负载通常并联，支路级执行器只能切下游回路，不能选其中一台；但照明、空调是否同属该支路必须勘查。第一代不装执行器，选择提供线索与人工复核——这是一条落地路线，**不宣称是唯一合理方式**。这也支撑两个决策：不做自动切断，避免误切正在写论文的电脑；把“可复核证据”本身当作工程价值。

## 第三部分 现状与差异化

### 3.1 先把行业事实说准

* **〔待核〕部分公开宿舍电表宣称具有恶性负载或移相负载识别。** 正式材料逐型号登记厂商、手册版本、选配项与页码；未取得原文前，不把某系列全部型号视为具备同样能力，也不写“现有产品只有总功率阈值”。
* **〔事实〕NILM 学术研究成熟**，PLAID、WHITED、BLUED、REDD、UK-DALE 等数据集与特征文献丰富。
* **〔边界〕宣传能力不等于内部算法或全工况性能。** 厂商未公开阈值、颗粒度与误报率，我们不做反向推断；没有同台实验，不声称本项目更准。

### 3.2 绝对不能说的三句话

1. “现有商业产品只能测总功率，无法识别恶性负载”——可能与公开手册直接矛盾。
2. “现有产品完全无法识别调压插座”——缺实测对照，部分型号宣称含选配功能。
3. “本作品准确率高于现有商业电表”——没有同台数据。

### 3.3 六维对照（先规定怎么查，再写查到哪一步）

| 维度 | 竞品处理规则 | 本作品当前状态 |
| :--- | :--- | :--- |
| 负载范围 | 逐型号记录已公开类别，不推断内部 | 指定设备/模式标签，范围〔待测〕 |
| 调压支持 | 核实型号与选配；未说明写“未说明”，不写“不具备” | 〔假设〕需正常非线性负载对照 |
| 事件记录 | 记录手册明示字段与接口 | 结构已设计，实现与追溯〔计划〕 |
| 判断依据 | 核查可访问数据，未公开不等于不具备 | 详情卡标来源、质量、算法版本〔计划〕 |
| 误报漏报 | 无同台测不比较准确率 | 报告原始计数、拒识、未知误接纳〔待测〕 |
| 成本 | 分清商品报价与 BOM 边界 | $228\text{ 元}$ 为旧清单估价；主机、存储、安全整改另计 |

### 3.4 三条可检验假设

* **D1〔假设〕解释性记录是否提高理解与核查便利？** 两种界面做任务对照与访谈，记理解正确性、完成时间与反馈；访谈偏好**不能**证明投诉率降低。
* **D2〔假设〕指定设备与档位中，谐波/波形能否区分调压负载与正常非线性负载？** 与主动 PFC、调速电机、调光器对照，报告误报漏报与未知；不从调压特征推断违规。
* **D3〔假设〕本地处理、授权、最短保存与删除是否满足核查与隐私要求？** 用字段审计、权限测试、删除测试与校方审查取证；无姓名学号**不等于**无隐私风险（房间＋时间＋波形仍可关联作息）。

### 3.5 差异化表述的三条证据标准

满足其一才可写“不同/更优”：① 有公开手册或论文直接支持该维度；② 有同条件、可复现的自测对照；③ 明确标“设计目标/待验证假设”并附验证协议。

## 第四部分 系统方案

### 4.1 架构总览

$$\text{支路} \xrightarrow[\text{隔离}]{\text{CT＋电压模块}} \text{RC 调理与钳位} \xrightarrow[\text{3200 Hz}]{\text{TIM＋双 ADC＋DMA}} \text{F103ZE 事件与特征} \xrightarrow{\text{UART}} \text{本地主机} \xrightarrow{\text{HTTP}} \text{Web}$$

职责切分：F103ZE 只做硬实时采样、事件检测与**已验证的低维特征**，不跑分类器；本地主机只做落库、比对与呈现，不参与 $3200\text{ Hz}$ 采样；Web 只读脱敏事件与缩略波形，不接触连续原始流。

> $3200\text{ Hz}$ 是**初始均匀采样率**，不是“每周期严格 64 点”。工频 $49.5\sim50.5\text{ Hz}$ 时每周期 $63.4\sim64.6$ 点；**首版按固定 64 点窗口分帧、不重采样**，频偏超目标后启用 5.4 方案 B。

### 4.2 测量单元

#### （1）电流通道：`SCT013-020`（$20\text{ A}/1\text{ V}$ 电压输出型）

* **状态**〔待核〕：若确为 $20\text{ A}/1\text{ V}$ 型，则内置采样电阻，二次侧直接输出 $0\sim1\text{ V}_{\text{rms}}$（名义 $50\text{ mV/A}$），接 ADC 前只需 $1.65\text{ V}$ 偏置、RC 与 `BAT54S` 钳位；**不能当电流输出型 CT 外接负载电阻**。
* **不用 `SCT013-000`（$100\text{ A}/50\text{ mA}$）**〔事实〕：量程浪费，小电流分辨率按名义比例恶化约 $5$ 倍；这是量程理由，不是精度保证。
* **名义量化**〔核算，前提：$V_{\text{ref}}=3.30\text{ V}$、12 位理想、$50\text{ mV/A}$〕：

$$\text{LSB}=\frac{3.30}{4096}\approx0.80566\text{ mV},\qquad k_i=\frac{0.80566\text{ mV}}{50\text{ mV/A}}\approx0.016113\text{ A/LSB}$$

  $1\text{ A}_{\text{rms}}\approx62.06\text{ LSB}_{\text{rms}}$；$0.1\text{ A}_{\text{rms}}$（$220\text{ V}$、$\text{PF}\approx1$ 时约 $22\text{ W}$）只剩约 $6.21$ 个 rms 码；$20\text{ A}$ 正弦在理想偏置下落于 $0.236\sim3.064\text{ V}$。
* **〔边界〕码数不是识别能力。** 从 $6.2$ 个码不能推出“$40\text{ W}$ 以下不可识别”，也不能推出“$100\text{ W}$ 以上可靠”：还缺噪声、谐波幅值、背景与可分性四类证据。$P=UI\cdot\text{PF}$，含 PFC 的电源不能按 $\text{PF}=1$ 换算。**本版取消统一能力下限**，改为 E1/E4 逐测量量给出范围。
* **CT 物理边界**〔事实〕：不测一次侧 DC；半波/不对称输入可能引起偏磁与失真，输出不对称不能当真实 DC；$20\text{ A}$ 是正弦有效值口径，高峰值因数可能更早削顶。
* **对照 CT**〔计划〕：`ZMCT103C`（$5\text{ A}/5\text{ mA}$，闭磁芯）只作实验室对照，须配负载电阻并守 $5\text{ A}$ 额定，不直接替换支路 CT；用途是评估开口 CT 小电流角差离散度，不是“解决偏磁”。

#### （2）电压通道：成品模块待审核（P0）

* **〔待核〕`ZMPT101B` 是互感器型号，不唯一确定成品板。** 限流电阻、运放后缀、偏置、滤波、隔离耐压与爬电距离随板型变化；`LM358` 摆幅须按实际厂商、负载、供电与温度核对，**不能把 $\text{VCC}-1.5\text{ V}$ 当固定保证**。
* **〔核算示例〕名义余量为什么不够**：若为 $5\text{ V}$ 供电、$2.50\text{ V}$ 中点、$220\text{ V}$ 对应 $\pm0.650\text{ V}$ 峰值，则输出 $1.85\sim3.15\text{ V}$；$+10\%$ 过压得 $3.215\text{ V}$，似有余量。但 $5\text{ V}$ 轨升到 $5.25\text{ V}$ 时偏置变 $2.625\text{ V}$，同样 $0.715\text{ V}$ 峰值下上峰达 $3.340\text{ V}$，**已越过 $3.30\text{ V}$**。电位器只调名义幅值，约束不了供电、偏置、增益与温度容差。
* **〔计划〕先审核，再接线**：取得准确板型/原理图，审核隔离、爬电、一次侧耐压与功耗；按最坏供电、偏置、增益、温度与故障输出选择衰减/缓冲/重偏置与限流；ADC 绝对最大额定值与注入电流按 ST 资料单独审核；考虑 MCU 断电与轨回灌。**未通过不接市电。**
* **标定**：幅频/相频实测；稳定可重复的系统误差可补偿，非线性削顶、漂移与不稳定误差**不能靠一次标定消除**；$k_u\approx0.3854\text{ V/LSB}$ 只是名义示例，量程利用率不等于 ENOB 或 SNR。
* **保护**〔计划〕：低压侧 RC＋`BAT54S` 钳位至 $3.3\text{ V}$ 轨；模块高压焊点加绝缘底座与阻燃外壳。**肖特基加外壳不能替代完整隔离与保护配合。**

#### （3）相位标定：基波、高次与“次级注入”分开

| 层级 | 参考 | 能标定 | 不能标定 |
| :--- | :--- | :--- | :--- |
| 基波一致性 | 电水壶（近似阻性，PF 不保证精确为 1） | 基波幅值、$\theta_{U,1}$ 与 $\varphi_{I,1}$ 一致性 | 高次相位；不能替代全频点 |
| 高次逐频点 | E1 低压侧注入 $50/100/150/250/350/550/750/1050\text{ Hz}$ 已知幅相正弦 | 各频点幅值比、相位差、重复性 | 真实 $220\text{ V}$ 下 PT 相移；CT 大电流非线性 |
| 完整链路 | L3 授权环境、完整电压通道与已知负载 | CT＋PT＋调理＋ADC 端到端残差 | 不能拿次级注入冒充，也不能单点外推全频段 |

* 电水壶只负责基波；高次由 E1 逐频点给出并记录不确定度。
* 次级注入绕过 PT 一次侧与高压限流，只验证注入点之后；完整链路必须完整通道。
* 无需计量级多谐波标准源；也不把“未做全频点标定”等同于“无法分类”——先用已验证阶次建基线，未验证阶次不进在线特征。

### 4.3 采样与同步

〔事实〕FFT 与相位对采样等间隔极敏感；软件轮询会引入微秒级抖动。

〔计划〕：

1. **硬件触发**：`TIM3` TRGO 以 $3200\text{ Hz}$ 触发 ADC；时钟、采样时间与触发映射按 RM0008 与实际库核对。
2. **双 ADC 规则同步**：ADC1 采电压、ADC2 采电流，同一触发沿锁存，**减少**通道时差；前端与 RC 的残余时延另标定，**不称“零延迟”**。
3. **循环 DMA＋软件乒乓**：$32\text{ bit}$（高 16 位电流、低 16 位电压）搬至 $2\times64$ 缓冲；HT/TC 只置标志与序号，主循环按所有权取用。这是**软件乒乓**，不等于硬件双缓冲。
4. **所有权与覆盖保护**：每半区带 `seq/owner`；处理超时会被覆盖，必须记 `overwrite_count/drop_count`，整段丢弃；**帧计数连续不能证明消费者没落后**。
5. **频率不是恒定 50 Hz**：连续 64 点不能自动视为整周期；采样索引与相位索引分开（5.3、5.4）。事件触发后的 hold-off、暂态等待与 post 窗截取见 5.1。

### 4.4 F103ZE 职责与资源

〔事实〕Cortex-M3、$72\text{ MHz}$、$64\text{ KB}$ SRAM、$512\text{ KB}$ Flash、**无 FPU**。

| 任务 | 在 MCU | 说明 |
| :--- | :---: | :--- |
| $3200\text{ Hz}$ 双通道采样与 DMA | 是 | 硬实时〔计划〕 |
| 滑动窗口事件检测 | 是 | 周期 RMS 与有功滑动比较〔计划〕 |
| 时域特征（$U_{\text{rms}},I_{\text{rms}},\text{CF}$、$P_{\text{meas}},S_{\text{meas}},\text{PF}_{\text{meas}}$ 及前后变化） | 是 | 不依赖 FFT/相位；耗时〔待测〕，不预填 $0.1\text{ ms}$ |
| 基波频域（64 点 RFFT、$P_1/Q_1$、可用阶次相量） | 验证后启用 | 依赖基波相位有效；接口见 5.5；耗时与内存〔待测〕，不预填 $0.5\text{ ms}$、$3\%$ |
| 带限重构与形状（$i_K$、$\text{CF}_{\text{diff}}$、LCR、半周能量比） | 验证后启用 | 依赖相量；仅事件时算 64 点，开销〔待测〕 |
| 暂态包络（$R_{\text{trans}},N_{\text{trans}}$） | 是 | 单周期 RMS 峰值与收敛周期 |
| 标准化、分类、数据库 | 否 | 交本地主机，便于迭代 |
| 深度学习推理 | 否 | 首版无必要；小样本过拟合风险高，非“物理不可能” |

〔核算〕$3200\text{ Hz}$、双通道、前后各 10 周期（$0.4\text{ s}$）原始缓存 $=1280\times2\times2=5120\text{ B}\approx5\text{ KB}$。**这只是原始缓存**，FFT 输入输出、方案 B 重采样（如启用）、协议缓冲、栈与中断另计，最终以 `.map` 与栈水位确认。

### 4.5 通信与本地主机

* **校赛**〔计划〕：树莓派只做预置 JSON 驱动的静态展示与回放（标“示意”）；省赛前再接串口实时落库。
* **协议**〔计划〕：`115200 bps`、8N1；**摘要包与波形包分开编号**，含协议/特征版本、长度、序号、CRC16。
* **包长**〔核算〕：每字节 $86.8\ \mu\text{s}$。摘要 $280\text{ B}\approx24.3\text{ ms}$（示例，不是完整包）；含 64 点 `int16` 波形的 JSON 可达 $546\text{ B}\approx47.4\text{ ms}$；二进制波形 $128\text{ B}$＋帧头约 $140\text{ B}\approx12.2\text{ ms}$。**以字段为准，不拿目标长度反推低延迟。**
* **发送纪律**〔计划〕：禁止在采样中断或主循环阻塞发送；写独立发送环形缓冲，由低优先级任务/DMA 发送，维护 `tx_producer/consumer` 与 `tx_drop`；生产连续**不能**发现消费落后。
* **仅事件上报**：保留既有设计，不降频、不换波特率。
* **上行/落库分工**〔计划〕：MCU 只发特征摘要帧与可选波形帧；`label`、`match_score`、`duration_ms`、`pair_status` 由主机生成或回填，`review_status` 人工填写。

## 第五部分 信号与特征

### 5.1 四步流水线

$$\text{ADC 码}\xrightarrow{\text{①偏置与标定}}u_{\text{meas}},i_{\text{meas}}\xrightarrow{\text{②分帧}} \text{pre/暂态/post}\xrightarrow{\text{③矩形窗 DFT}} \text{有效值/功率/相量}\xrightarrow{\text{④差分与门控}}\mathbf{x}$$

首版 ② 直接用 64 个原始采样点分帧，不做重采样；DFT 分“数学参考”与“库实现”两层；最后加质量门控——**质量不合格的特征不进分类**。

〔事件状态机与 hold-off〕触发前保留 $M_{\text{pre}}$（初值 5）个稳态周期；触发后进入暂态观测窗：① 抑制重复触发（hold-off，初值 10 个工频周期，可配）；② 等包络收敛（连续 $K$ 周期相对变化低于阈值，$K$ 初值 3）或到达最大窗长（初值 10 周期）；③ 再截取 $M_{\text{post}}$（初值 5）个稳态周期；④ 超时未收敛则用末段窗口并置 `uncertain`；若窗内出现第二个独立阶跃，标 `multiple`。参数由 E4 标定，不写成物理常数。

〔首版最小可实现集〕时域 $U_{\text{rms}},I_{\text{rms}},P_{\text{meas}},\text{CF}$＋事件状态机＋质量标志＋UART 摘要＋主机落库/展示；FFT 与基波 $P_1/Q_1$ 在 L0/E3 通过后接入；谐波与带限重构再往后；分类器最后接入。

〔实现顺序〕① L0 数组回放与 Python/MCU 对清；② 固定 64 点窗口＋矩形 DFT＋时域 $P_{\text{meas}}/I_{\text{rms}}$；③ 事件状态机（pre/暂态/post、hold-off）；④ 质量门控与 UART 摘要；⑤ 基波 $P_1/Q_1$ 与谐波；⑥ 分类器与 Web 回放。

### 5.2 抗混叠与传感器带宽

#### （1）完整两级 RC 传递函数

〔核算〕输入→$R_1$→节点 A（$C_1$ 接地）→$R_2$→输出（$C_2$ 接地），忽略源阻抗与负载：

$$H(s)=\frac{1}{1+s(R_1C_1+R_1C_2+R_2C_2)+s^2R_1R_2C_1C_2}$$

代入 $1\text{ k}\Omega/100\text{ nF}$ 与 $10\text{ k}\Omega/10\text{ nF}$ 得 $H(s)=1/(1+2.1\times10^{-4}s+10^{-8}s^2)$。**不能把两个互不加载的一阶网络直接相乘**：第二节阻抗高 $10$ 倍只能**减小**级间加载，不能“消除”。

| 频率 | $\lvert H\rvert$ | 衰减 | 相移 |
| :---: | :---: | :---: | :---: |
| $50\text{ Hz}$ | $0.9988$ | $-0.010\text{ dB}$ | $-3.8^\circ$ |
| $150\text{ Hz}$ | $0.9894$ | $-0.092\text{ dB}$ | $-11.3^\circ$ |
| $350\text{ Hz}$ | $0.9454$ | $-0.49\text{ dB}$ | $-25.9^\circ$ |
| $1050\text{ Hz}$ | $0.668$ | $-3.50\text{ dB}$ | — |
| $1600\text{ Hz}$ | $0.474$ | $-6.49\text{ dB}$ | — |

两级 $-3\text{ dB}$ 截止为 $956\text{ Hz}$（不是 $1024\text{ Hz}$）。

#### （2）通带校准 ≠ 抗混叠

通带补偿可修正稳定的幅相误差，**不能撤销已折叠的带外信号**，还会放大噪声。通带校准指 $50\sim350\text{ Hz}$ 逐频点测幅相并补偿；抗混叠指靠模拟阻带与采样率约束所有可能折叠的分量。

〔计划〕按最高特征频率、预期带外干扰与允许折叠误差评估阶数/截止/采样率，比较缓冲、增强滤波、过采样后降采样；低压带外注入评估残余混叠；**未通过不称“抗混叠充分”**。当前**保留 $3200\text{ Hz}$ 与现有 RC**，不把提高采样率列为必改项，也不写“带外误差低于噪声”。

#### （3）传感器带宽

〔事实〕`SCT013-020` 手册仅标 $50/60\text{ Hz}$，无 $150\sim1050\text{ Hz}$ 曲线。E1 扫频是第一道关卡：若 $350\text{ Hz}$ 幅值比与补偿后相位残差**同时**不达标，谐波退回 3 次；不凭单点 $0.5/0.9$ 阈值启停，也不由 $1050\text{ Hz}$ 失败推断 $350\text{ Hz}$ 失败。

### 5.3 采样索引、周期相位与偏置

〔计划〕$3200\text{ Hz}$ 为初始值；工频约 $50\text{ Hz}$ 时名义 64 点/周期，频偏时不是。**首版方案 A 不重采样**：直接把 DMA 的 64 个原始采样点当作名义一周期窗口，依靠 5.6 的 $h\theta_{U,1}$ 逐窗校正初相基准（**不消除非整周期泄漏**）；只有频偏超目标、启用方案 B 时，64 点才表示等相位重采样网格 $N_{\text{phase}}=64$。数据结构上采样索引与相位索引分开，是为 B 预留，**不代表首版已重采样**。

〔定义〕$a_u,a_i$ 为原始码，$b_u,b_i$ 为估计偏置：$u_{\text{meas}}=k_u(a_u-b_u)$，$i_{\text{meas}}=k_i(a_i-b_i)$；$k_u,k_i$ 实测，不写死名义常数。

〔计划〕比较零输入偏置、慢速跟踪、整周期均值；若用均值，须明示输出是**该窗口的零均值交流分量**；暂态、非整周期与半波需检查偏置被污染。

〔边界〕CT 不能测一次侧 DC，加回均值也不能恢复；理想半波与“去 DC 半波”的 CF、低电流占比、半周能量比不同，不能把后者当原始半波指纹；用 L0 已知参考量化处理偏差。

### 5.4 窗口与频率：撤下单周期 Hann

〔核算〕$w[n]=0.5-0.5\cos(2\pi n/N)$ 使 $Y[k]=0.5X[k]-0.25X[k-1]-0.25X[k+1]$。$N=64$ 覆盖一周期时相邻谐波隔一个频点，纯基波在 $k=2$ 产生 $0.25|X_1|$，而 $|Y_1|=0.5|X_1|$：

$$\frac{|Y_2|}{|Y_1|}=50\%$$

**纯正弦也会得到 $\text{HRI}_2\approx50\%$**，足以冲撞“半波 $>35\%$”判据；乘 $2.0$ 只校正孤立谱分量尺度，**不能去除串扰**。

| 方案 | 做法 | 阶段 | 边界 |
| :--- | :--- | :--- | :--- |
| A 矩形窗＋固定 64 点 | 取 64 个原始采样点、去均值、矩形窗、未缩放 DFT，**不重采样** | **首版基线（代码先走这条）** | 频偏时窗口非整周期，泄漏随频偏增大；只在工频正常范围用，超目标转 B |
| B 同步跟踪＋重采样 | 由电压通道估 $f_0$ 与相位，按整周期截取并重采样到 64 相位点 | 频偏超目标后的**第一备选** | 需处理估计误差、畸变与插值误差；不称“无泄漏”；暂不改 `TIM3` ARR |
| C 多周期加窗 | $M$ 周期，第 $h$ 次落在约 $hM$ 频点 | 后续候选 | 需重定义索引、相干增益与频偏误差 |

〔决定〕**取消 Hann 与 $\times2.0$，首版用 A（固定 64 点、矩形窗、不重采样）**；频偏误差由 L0 扫频测试判定，超目标再上 B，不立即上 C。

### 5.5 数学参考与库实现

〔定义〕$x[n]$ 为无削顶、已周期化的 $N$ 点实序列：

$$X[h]=\sum_{n=0}^{N-1}x[n]e^{-j2\pi hn/N},\qquad J_h=\frac{\sqrt{2}}{N}X[h]\quad(1\le h<N/2)$$

DC 与 Nyquist 单独处理；多周期/非整周期时 $h$ 不等于输出频点索引。

* **首版锁 `arm_rfft_fast_f32`**：64 点输入，输出 **64 个 float**，顺序 $[X_0,X_{N/2},\mathrm{Re}_1,\mathrm{Im}_1,\dots]$；$k$ 次实部 `fft_out[2*k]`、虚部 `[2*k+1]`。F103 无 FPU，但每 $20\text{ ms}$ 只跑一次，软浮点最坏耗时〔待测〕。
* **若用 `arm_rfft_q31`**：审阅记录指出（须以实装版本复核）需 **128 个 `q31_t`、Q7.25 定标**，索引与幅值换算均不同；本版按此预留，**禁止与 f32 共用 `fft_out[64]`**。
* Q15、Q31 与软浮点各有缩放、精度与时间代价；**不预断 Q15 不可用**，也不凭位宽证明小信号可测。以实装 `arm_math.h` 与源码为准，锁版本；先用 Python 未缩放 DFT 交叉核对，再决定是否切定点。

〔幅值〕矩形窗、整周期、未缩放前提下：$I_{\text{peak},k}=2|X_k|/N$，$I_{\text{rms},k}=\sqrt{2}|X_k|/N\approx0.022097|X_k|$。

〔自检〕纯正弦→已知高次→已知相位混合波→不同起点/频偏→近零幅值（相位应标缺失）。

### 5.6 相位归一化

$$\varphi_{I,h}=\text{wrapToPi}\left(\theta_{I,h}-h\theta_{U,1}-\Delta\phi_{\text{cal},h}\right),\qquad \Delta\phi_{\text{cal},h}=\phi_I(hf_0)-h\phi_U(f_0)$$

〔符号约定〕$\varphi_{I,1}>0$ 表示电流超前电压（容性），$\varphi_{I,1}<0$ 为感性。本项目取 $P_1=U_1I_1\cos\varphi_{I,1}$、$Q_1=-U_1I_1\sin\varphi_{I,1}$，使**感性无功为正**；代码中不得写成 $+U_1I_1\sin\varphi_{I,1}$。

$h$ 倍旋转校正**共同时间起点平移**，不修复非整周期泄漏、削顶、幅值依赖相移、频率估计误差或背景变化；“与截断完全无关”“完全消除模块相移”均超出适用范围，已删。

高次相位只在幅值超过可靠门槛时使用，接近零标缺失；$\Delta\phi_{\text{cal},h}$ 由 E1 逐频点给出并报残差，**不用一次电水壶实验代替全部高次标定**。只用电压基波作时间参考，不代表测总有功也只需基波——功率通道的带宽、滤波与对齐另行验证。

### 5.7 公开数据预处理

* 先核验版本、许可、电网、通道、幅值单位与**有无同步电压**；PLAID 优先，WHITED 无同步电压则不做电压参考相量法。
* 降采样用与目标采样率、过渡带、阻带匹配的抗混叠处理，不能只用二阶约 $1\text{ kHz}$ 低通；模拟前端等效仿真另做一条链，用实际幅相与噪声，不强制两通道相同。
* $60\text{ Hz}$ 仍是 $60\text{ Hz}$：可选 $3840\text{ Hz}$ 或按估计周期重采样；不是“禁止重采样到 $3200\text{ Hz}$”，而是之后不能仍按一周期 64 点直接取谐波。跨电网数据只做方法核验，不直接代表 $220\text{ V}/50\text{ Hz}$ 部署。

## 第六部分 特征与判别

### 6.1 四类差分对象：时域基线、基波标量、相量增强、带限展示

| 对象 | 作用对象 | 前提 | 边界 |
| :--- | :--- | :--- | :--- |
| ① 时域标量（最小基线） | $\Delta P_{\text{meas}}$、$\Delta I_{\text{rms}}$ | 无 FFT/相位依赖；背景相对稳定 | $\Delta I_{\text{rms}}$ **不是**新增设备 $I_{\text{rms}}$；受背景波动影响 |
| ② 基波频域标量 | $\Delta P_1$、$\Delta Q_1$、$\text{DPF}_1$ | 基波相位有效、标定有效 | 本质是 $\Delta J_1$ 的实/虚部；基波相位失效时同步失效；不依赖高次谐波带宽 |
| ③ 复相量差（增强） | $\dot I_h=I_{\text{rms},h}e^{j\varphi_{I,h}}$ | 标定、共同相位、前后稳态 | 近似新增负载谐波，**也含背景、供电扰动与测量误差**；不称“精确剥离” |
| ④ 带限重构（展示） | $K=\{1,2,3,5,7\}$ 阶相量差 | 相位一致、阶次与版本明确 | 不是真实新增设备完整电流，不能直接套原始波形阈值 |

> 波形来源：首版只产 `raw` 与 `bandlimited`；`aligned_diff` 指方案 B 重采样后按电压正过零点对齐的时域差 $i_{\text{post}}[n]-i_{\text{pre}}[n]$，**首版不重采样，不产出该类型**。

### 6.2 相量差与带限重构

#### （1）复平面平均

$$\bar J_{h,\text{pre}}=\frac{1}{M_{\text{pre}}}\sum_m J_{h,m,\text{pre}},\qquad \bar J_{h,\text{post}}=\frac{1}{M_{\text{post}}}\sum_m J_{h,m,\text{post}}$$

**不分别平均幅值与包裹角度**。$\Delta J_h=\bar J_{h,\text{post}}-\bar J_{h,\text{pre}}$，$A_h=|\Delta J_h|$，$\psi_h=\arg\Delta J_h$；仅当 $A_1$ 超过可靠门槛且质量有效时算 $\text{HRI}_h=A_h/A_1$；弱谐波相位标缺失。

#### （2）$D_K$ 不是总 THD

只提 $K=\{1,2,3,5,7\}$ 却对 $k=2\dots7$ 求 THD，缺 4、6 次。改为：

$$D_K=\frac{\sqrt{\sum_{h\in K,h>1}A_h^2}}{A_1}\times100\%$$

称“**所选谐波集合的畸变指标**”；要报 2–7 阶截断 THD，必须提全 2–7 阶。

#### （3）带限重构

$$i_K[n]=\sum_{h\in K}\sqrt{2}A_h\cos\left(\frac{2\pi hn}{64}+\psi_h-\frac{h\pi}{2}\right),\quad n=0\dots63$$

纯阻性（$\psi_1=0$、无高次）时 $i_K=\sqrt{2}A_1\sin(2\pi n/64)$，$n=0$ 起零上升——这是**恒等式核对**，不是“任意电器都能重构”。$i_K$ 缺 DC 与未提取高次，不能还原真实半波的平台、尖峰与完整能量；形状特征名称须带 $K$ 与 `bandlimited`。

#### （4）半波与正弦的两个反直觉核算

〔核算一〕理想半波 $i(\theta)=I_p\sin\theta$（$0<\theta<\pi$），直流 $I_p/\pi$；去 DC 后只留 1、2 次（理想半波 3/5/7 次为零）：

$$x(\theta)=\frac{I_p}{2}\sin\theta-\frac{2I_p}{3\pi}\cos2\theta$$

令 $a=I_p/2$、$b=2I_p/(3\pi)$，则 $E_{1,2}=\frac{\pi}{2}(a^2+b^2)\pm\frac{4}{3}ab$，

$$\eta_{\text{sym}}=\frac{E_1}{E_2}=\frac{0.4634+0.1415}{0.4634-0.1415}\approx1.88$$

**理想半波经“去 DC＋有限阶重构”后约 $1.88$，不是“$\gg1$”**；删除“极度不对称”预设，改用 $1.88$ 做 L0 参考值，真实偏离由 E4 测。

〔核算二〕纯正弦在 $\alpha=0.15$ 时低电流占比为 $\frac{2}{\pi}\arcsin0.15=9.59\%$，64 点为 $6/64=9.38\%$。对上面的半波重构波形：正峰 $0.7122I_p$；负半周因直流被滤除而整体下移，取值只在 $[-0.3595,-0.2122]I_p$，即幅值占正峰的 $29.8\%\sim50.5\%$——**负半周没有任何一点落入 $\alpha=0.15$ 的低电流区**，低电流样本全部来自正半周两个过零点附近，连续积分 $9.34\%$、64 点为 $6/64=9.38\%$，与纯正弦几乎相同。**所以半波重构的 LCR 不会出现“半周期死区≈50%”，甚至不比正弦高**；LCR 不能单独作半波判据，$\text{ZCR}_{\text{dead}}\approx0.095$ 只是正弦的几何事实。

#### （5）失效传播

相量失效时，$A_h$、$\text{HRI}_h$、$D_K$、$i_K$ 及全部形状特征（$\text{CF}_{\text{diff}}$、低电流占比、半周能量比）**同时失效**，不得继续输出为有效特征。

### 6.3 六组候选特征

| 组 | 定义 | 作用 | 边界 |
| :--- | :--- | :--- | :--- |
| **G1 稳态** | $I_{\text{rms}}$、$I_{\text{peak}}$、$\text{CF}$ 及前后变化 | 阻性接近正弦；部分无 PFC 适配器呈高峰值 | 基于 `raw` 支路测量；`aligned_diff` 仅方案 B；**不预设**笔记本 $\text{CF}\in[2.2,4.0]$、游戏本 $>2.5$ |
| **G2 谐波** | 可用阶次前后相量、$\Delta J_h$、$\text{HRI}_h$、$D_K$、$\cos\psi_3/\sin\psi_3$ | 区分线性、全波整流、半波/调压 | 依赖带宽、角差与 $A_1$ 门槛；$\text{HRI}_3<3\%$、$>50\%$、$\text{HRI}_2>35\%$ **不作未确认规则** |
| **G3 功率** | $P_{\text{meas}}=\frac1N\sum u_{\text{meas}}i_{\text{meas}}$、$S_{\text{meas}}$、$\text{PF}_{\text{meas}}=P_{\text{meas}}/S_{\text{meas}}$；另列 $P_1=U_1I_1\cos\varphi_{I,1}$、$Q_1=-U_1I_1\sin\varphi_{I,1}$、$\text{DPF}_1=P_1/(U_1I_1)$（**感性无功为正**） | 最可靠基线；基波分解 | $P_1/S_{\text{meas}}$ **不是真实总 PF**；非正弦下总功率还含同阶谐波贡献 |
| **G4 标量变化** | 时域：$\Delta P_{\text{meas}},\Delta I_{\text{rms}}$；基波：$\Delta P_1,\Delta Q_1,\text{DPF}_1$、基线稳定性 | 时域不依赖 FFT；基波需相位有效 | 相位失效时只剩时域量；均受背景波动影响；事件 DPF 用 $\Delta P_1,\Delta Q_1$ 并标条件 |
| **G5 暂态** | $R_{\text{trans}}=\dfrac{\max_{m\in\mathcal{T}}I_{\text{rms}}[m]-I_{\text{rms}}^{(\text{post})}}{I_{\text{rms}}^{(\text{post})}-I_{\text{rms}}^{(\text{pre})}}$、$N_{\text{trans}}$ | 同支路包络相对**稳态阶跃**的归一化暂态偏差与收敛 | $\mathcal{T}$ 为暂态观测窗；仅合闸（$\Delta I>0$）计算；$\lvert\Delta I_{\text{rms}}\rvert<\kappa_I$（由 E4 标定）或 $I^{(\text{post})}\le0$ 标缺失；空载 E4（$I^{(\text{pre})}\approx0$）仍可算；**无浪涌 $\approx0$**；负值表示爬升型（暂态未超过稳态）；不等于新增负载自身浪涌 |
| **G6 形状** | $\text{CF}_{\text{diff}}$、$\text{LCR}(\alpha)=\frac1{64}\sum\mathbb{I}(\lvert i_K\rvert<\alpha\max\lvert i_K\rvert)$、半周能量比 | 调压/整流的辅助描述 | $\text{CF}_{\text{diff}}\neq\text{CF}_{\text{post}}-\text{CF}_{\text{pre}}$；LCR 是**全周期低电流占比**，不是过零死区；$\alpha$ 由训练/验证选，不预置 $0.30$ |

〔顺序〕先用已校准 G1 与功率变化建低维基线；G2/G5/G6 经“增量有效性＋消融”后加入；标签与物理属性分开，不用单一形状量认定违规。

### 6.4 质量门控与拒识

* 条件：采样/缓存完整、无削顶、幅相标定有效、频率/相位可靠、目标谐波信噪比足够、前后有稳定窗口、未发现重叠变化。
* 背景稳定性不只看事件前 5 周期功率标准差，还比较前后窗口、谐波方差与电压变化；$15\text{ W}$ 只作待验证候选。
* `invalid` 不分类，报故障；`uncertain` 保存并输出“无法确定/混合”，不强行单设备。
* 仅高次谐波失效而基波相位有效时，可用**单独验证过**的基波标量模型；基波相位也失效时，只剩 $\Delta P_{\text{meas}},\Delta I_{\text{rms}}$ 时域模型；背景不稳时标量/暂态也可能失效，不能“降级后仍给可靠类别”。
* 未检出第二阶跃不等于没有同时事件；完全重合事件可能不可分。质量与类别是两维，`valid+unknown` 合法。

### 6.5 基线分类与开放集拒识

* 首版比较标准化等权最近邻（$k=1/3$）与浅层决策树（深度 $\le4$）；加权须明确权重与选择过程，零方差特征删除或显式处理；示意树标“假想规则”，不放未经训练的 $300\text{ W}$、$0.28$。
* 指纹库与在线必须同特征来源、同标定、同窗口、同版本；单设备原始指纹不能直接匹配混合支路总 RMS 差。
* 按设备实例/录制批次分训练、验证、测试；拒识阈值用验证集**留出的未知设备/工况**，平衡已知拒识与未知误接纳，不能只用已知类 ROC 证明未知识别。
* `unknown` 与 `uncertain/invalid` 分开统计；报告覆盖率、拒识率、未知误接纳与混淆矩阵，不剔除失败样本。

## 第七部分 设计核算与可验证性分析

对应 **D5《设计核算与验证方案》**。本部分给出名义量程、容差、资源预算、失效模式与分层验证协议，用来**排除设计矛盾、识别风险、说明下一步怎么验证**；不在未实测时证明分类可靠、安全已验收或失效已可控。

### 7.1 三个问题

1. **参数与接口是否一致？** 例如宣称测 $10\text{ W}$ 却选 $20\text{ A}$ 量程配 12 位 ADC，提示小信号风险；但不能不看增益、噪声与目标特征就断言“必然不可测”。
2. **哪些余量能算，哪些必须测？** ADC 名义 LSB、RC 传递函数、SRAM 原始缓存可算；实际 ENOB、CT 角差、板级摆幅、最坏耗时必须测。
3. **失效如何发现，哪些发现不了？** FMEA 要列“可自动检测”“只能靠安装检查”“可能漏检”三类；不可检测不是隐瞒，是工程诚实。

### 7.2 误差来源、前提与验证

| 误差源 | 名义核算与前提 | 状态 | 验证方法 |
| :--- | :--- | :--- | :--- |
| ADC 量化/噪声 | $3.30\text{ V}$、12 位：$0.80566\text{ mV/LSB}$；$0.1\text{ A}$ 约 $6.21$ rms 码 | 〔核算〕；ENOB 11 位只作敏感性情景，不是实测，也不等同 $\pm1.61\text{ mV}$ 误差界 | 空载噪声、参考与偏置漂移、多幅值线性；按规定方法测 ENOB/SINAD |
| CT 线性/角差 | 手册只给 $50/60\text{ Hz}$；$1\%\sim3\%$、$1^\circ\sim4^\circ$ 不作已知结论 | 〔待核/待测〕 | E1 全链路幅相＋重复性；标定表注明幅值、频率、温度与不确定度；对照 `ZMCT103C` |
| 电压模块 | 名义 $2.50\text{ V}$ 中点、$\pm0.650\text{ V}$ 峰值；$+10\%$ 为 $3.215\text{ V}$；$5.25\text{ V}$ 供电时 $3.340\text{ V}$ 越界 | 〔核算示例〕，证明名义余量不足 | 取得板型/原理图；按最坏供电、偏置、增益、温度与故障审核；实测 SNR、摆幅、相位 |

| 采样时序 | 硬件触发降低软件抖动；$50\text{ ns}$ 为情景值，非保证 | 〔核算示例〕 | 触发输出/时钟、已知双通道相位参考、序号与长时一致性；记可辨时差 |
| 频偏与窗 | 首版矩形窗＋整周期；单周期 Hann 使纯正弦 $\text{HRI}_2\approx50\%$ | 〔核算〕 | 纯正弦/已知谐波/随机起点扫频，测串扰、幅相偏差；不写未测的 $1\%\sim3\%$ |
| 总预算 | 可重复偏差、随机噪声、模型误差与失效条件分开；**不直接 RMS 合成** | 〔计划〕 | 每特征记“允许误差、参考方法、状态、实测”四栏；阈值由分辨需求确定，未定处留“待定” |

### 7.3 FMEA：区分可检测与可能漏检

| 失效 | 影响 | 可检测性与边界 | 处置 |
| :--- | :--- | :--- | :--- |
| **F1 断线/偏置异常/ADC 到顶** | $U_{\text{rms}}$ 跌落或削顶，功率与相位失真 | 看原始码轨距离、长平顶、偏置、输入量级与参考有效性；`ADC_u>=4090` 命名“ADC 到顶告警”，只覆盖接近满量程；$190\sim250\text{ V}$ 为待验证候选 | 停相关特征与分类，提示“电压通道异常”；校准后点胶。不改 3980，不把 LM358 当轨到轨 |
| **F2 CT 未闭合/安装异常** | 读数偏小、角差增大 | 已知参考负载可辅助；不填 $30\%\sim70\%$；**在线无参考时不能保证自动发现** | 提示检查卡扣与接线；把安装检查写进运维流程 |
| **F3 缓冲覆盖/丢帧** | 时间断层，频谱伪峰 | 生产/消费序号、处理超时、半区所有权、`overwrite_count`；**帧计数连续不等于采样无缺失** | 丢弃污染窗口，累加计数，置 `invalid`；时序另做独立验证 |
| **F4 重叠事件** | 相量差混合两台设备 | 可分辨的多个阶跃可标“混合”；**恰好同时或相互抵消可能漏检** | 标 `multiple/uncertain`，不强行单类；保留原始计数 |
| **F5 背景波动** | 基线失真，污染差分 | 同时检验前后稳态与特征稳定性；$15\text{ W}$ 为候选 | 不确定则拒识或仅记录；只有独立验证过的简化模型才可调用，不宣称标量/暂态免疫背景 |
| **F6 未知设备** | 强行归类造成误报 | 标准化距离＋验证集选择的拒识；记未知误接纳与已知拒识 | 输出 `unknown`，保留功率与可用波形；质量故障与未知分开 |

### 7.4 可测试性设计

1. **模拟测试点**：只在**已确认与危险电压隔离的低压侧**引出 `TP_I_BIAS`、`TP_I_OUT`、`TP_V_OUT`、`GND`；偏置/摆幅按实物定义；示波器地夹与保护地关系须审核，避免跨隔离危险连接。
2. **采样节拍（PA8）**：每次 64 组样本的 DMA 半满/全满回调翻转一次，$3200\text{ Hz}$ 下每 $20\text{ ms}$ 翻转，即 **25 Hz 方波、间隔 20 ms**（v0.4.1 的“50.00 Hz”把半周期当周期）。该信号只观察 DMA 处理节拍，**不能证明样点等间隔或两通道零时差**；采样时序另用触发输出、已知相位参考与数据序号验证。
3. **回环与测试箱**：串口数组回放只验证解码、FFT、缩放与特征，不经过传感器与 ADC；桌面支路箱的阻燃、接地、端子与防触及由具备条件人员审核，**透明罩不是安全充分条件**；校赛只交方案，不要求新手自行制作强电箱。

### 7.5 关键一致性核对

| 项 | 来源 | 当前结论 |
| :--- | :--- | :--- |
| `SCT013-020` 输出与灵敏度 | YHDC 原厂手册（准确型号/批次） | 〔待核〕若确为 $20\text{ A}/1\text{ V}$，则名义 $50\text{ mV/A}$、内置电阻；不以“已核实”替代批次核对 |

### 7.6 分层验证协议

| 层 | 做法 | 验证 | 不能证明 |
| :--- | :--- | :--- | :--- |
| **L0 软件** | Python 生成纯正弦、已知 2/3/5/7 阶幅相、随机起点、频偏、理想/去 DC 半波、背景叠加；固件回放 | 解码、DFT 尺度、数组布局、$h$ 倍归一化、特征代码 | ADC、传感器、模拟前端与安全 |
| **L1 低压下游注入** | 在指导人员确认的测试点注入 ADC/AFE 允许的信号；先核实幅度标定、$50\ \Omega$ 源阻抗、共地、偏置与保护 | 注入点之后电路与算法 | 绕过传感器则**不是**完整 CT/PT 标定 |
| **L2 低压磁耦合** | 多匝穿 CT，用适当参考测实际电流与相位；必要时用经审核的低压驱动 | CT 小信号幅相与重复性 | 大电流非线性；CT 对 DC 与半波偏磁的限制；不默认函数源可长期输出 $50\text{ mA}$ |
| **L3 完整链路** | 具备条件人员监督的批准设施，接完整电压通道与已知负载 | CT＋PT＋调理＋ADC 端到端残差 | 次级注入不能冒充；隔离变压器 $220\text{ V}$ 仍是危险电压，不归入低压 |

〔L2 能力核算〕源开路 $20\text{ V}_{\text{pp}}$（$7.07\text{ V}_{\text{rms}}$）、源阻抗 $50\ \Omega$、串 $100\ \Omega$，总阻抗约 $150\ \Omega$：

$$I_{\text{src}}=\frac{7.07}{150}\approx47.1\text{ mA}_{\text{rms}}$$

经 20 匝，磁动势等效一次侧约 $0.94\text{ A}_{\text{rms}}$。**这是磁动势等效，不是功率等效**；适合小信号与局部响应，不能覆盖全部负载电流；大电流特征由 E4/E5 观察，不另造标准源。

〔纪律〕高次相位需已知且足够幅值的对应频率分量与可靠基波参考；未锁相的两台源不能假定相位关系；电水壶只做基波一致性，不保证 PF 精确为 1。每层记来源、覆盖环节、参考不确定度、幅相残差、重复性与失败条件；可用阶次由逐阶结果定，不靠单点 $0.5/0.9$，当前不冻结 $2^\circ$、$1\%$ 门槛。

### 7.7 校赛结论

> “当前完成度以实际材料为准。设计核算给出了名义量程、主要误差来源、资源需求与分层验证路线，**尚未证明**具体功率下的识别可靠性。先在指定设备与授权工况建立事件基线，再检验谐波与暂态是否改善；无法确定时拒识。原型、完整标定与实物性能留待省赛前。”

### 7.8 为什么校赛不赶 Demo

校赛不要求 Demo，优先把测量接口、特征定义、验证协议与状态口径做实，不用未标定数据制造完成印象。两周还要扣除采购、安全审核、仪器学习与返工；仓促样机在答辩现场特征跳变，反而损害可信度。有余力可展示 L0 已知信号自检，并明确它只覆盖软件层。**没有 Demo 不是技术已成立的证据，也不是回避验证**；下一阶段以安全审核与实测验收。$4\sim5$ 周是候选排期，不是完成保证。

### 8.3 公开数据两晚时间盒

* 优先 PLAID（$30\text{ kHz}/60\text{ Hz}$），WHITED 补充；两晚只做版本/许可/通道核查、代表性波形、一个可追溯记录的特征自检；有余力再做按组简单分类。
* 无同步电压则不做电压参考相量法或有功验证；无事件前后与组合真值则不称“真实混合 NILM 验证”。合成叠加须明确共同相位/频率假设，单列“合成机制实验”。
* 两晚未完成可用性即停止，不装 `NILMTK`；最多退到“有可追溯真值的公开分表功率事件基线”，并注明未验证谐波；连简化结果也没有则全部留计划，**不得写“验证成功”**。

### 8.4 数据划分

* 验证“同设备新录制”按事件组/录制批次划分；宣称“跨设备泛化”按设备实例留出；`GroupShuffleSplit` 可用，但检查类别覆盖并另留验证集。
* 事件分组符合当前验证目标，**不是泄漏**；真正的泄漏是同一段连续运行的相邻周期同时进训练与测试。
* 特征筛选、均值方差、阈值与模型选择只用训练/验证集；测试集冻结，只做一次前向评估。

### 8.5 评估口径

1. **事件检测**：定义起止真值、匹配容差与一对一规则；报 TP/FP/FN、精确率/召回率；漏检不能从系统级分母消失。
2. **类别识别**：原始计数混淆矩阵，含未知真值、`unknown`、`uncertain`、多重事件；分别报已知类正确率、接受覆盖率、拒识率、未知误接纳、质量失败。
3. **用途评估**：先定义目标负载/工况、正常对照与分母；不把“发热”等同违规；未知与质量失败如何计入须预先说明。
4. **延迟**：分“发生→检测→特征就绪→落库→界面提示”四段；$<1.0\text{ s}$ 只是待验证目标，记样本与场景，不只给最快值。
5. **诚实报告**：报告所有安排场景的次数与失败，不用“有效已知子集”冒充整机性能；少样本只支持当前设备/工况。

## 第九部分 三个核心假设与退路

### 9.1 H1：相位信息是否带来可重复增益

* **〔假设〕** 在指定设备、稳定背景、可靠共同相位与幅相标定下，复数谐波差相对同阶幅值差与低维时域标量基线，是否改善特征估计或类别辨识？
* **〔证据〕** 同一事件、同一划分、同一任务，比较幅值差、复数差、不做差分的总量特征；看谐波残差、分类计数、拒识与开销。对 THD/HRI 直接相减只作**错误物理解释示例**，不把“击败它”当先进性。
* **〔退路〕** 先查估计器、相位门槛、背景、滤波、参考与传感器，**不全部归因 CT**；退回**时域标量基线** $\Delta P_{\text{meas}},\Delta I_{\text{rms}}$，$\Delta P_1/\Delta Q_1$ 仅在基波相位仍有效时保留；**停用相量差时同步停用 $\text{CF}_{\text{diff}}$、低电流占比、半周能量比与带限重构**，不要求降级算法消除背景变化。

### 9.2 H2：稳态与暂态是否改善指定混淆场景

* **〔假设〕** 在同一批标注数据上，稳态基线、加谐波、加暂态、联合特征，哪一种真正降低指定场景（调压水壶 vs 电吹风低档 vs 多台游戏本）的误报？
* **〔证据〕** 同划分消融；调压与正常非线性（主动 PFC、调速电机、调光器）对照；报误报、漏报、未知与覆盖率；多设备同时变化作困难场景，不当单电器标签。
* **〔退路〕** 无改善则保留更简单基线并说明范围；只有误差分析指出“采样率是瓶颈”才比较 $6400\text{ Hz}$，**提高采样率不是自动改善**，也不能恢复 CT 丢失的 DC 或解决物理不可分。

### 9.3 H3：可解释记录与本地最小化是否实用

* **〔假设〕** 说明来源、质量、权限、保存/删除与追溯，能否帮助核查并被理解？
* **〔证据〕** 与核验过的具体产品公开能力对照；做任务测试、权限/删除测试与校方隐私审核；**不以“无身份字段”宣称无隐私风险**。
* **〔退路〕** 按实际任务简化展示，保留专家入口；没有投诉数据不声称减少投诉。

### 10.2 电气安全五条红线

1. **严禁未经授权私拆配电箱**：无后勤书面许可与指导教师监护，不触碰真实宿舍配电箱内部线路。
2. **严禁非隔离直连市电**：不用电阻分压把 $220\text{ V}$ 接入单片机、示波器地线或电脑 USB/声卡。
3. **先软件与安全低压，再授权强电**：L0–L2 完成并写清覆盖环节；完整市电链仍须授权。**隔离 $220\text{ V}$ 不是安全低压**，不允许仪器地线或 USB 形成跨隔离危险连接。
4. **保护由具备电气条件人员审核**：**空开与保险丝串接于供电路径，MOV 跨接被保护节点（相—零或相—地）并与过流保护协调**；按线路/负载额定、绝缘、接地、防触及、过流与漏电审核；MOV 考虑失效、过流/热保护、额定与位置；**互感器裸件耐压不等于成品板/整机认证**，透明罩不替代绝缘阻燃；未经批准不自行搭接市电。
5. **第一代不装自动断电继电器**：未完成带载寿命、触点粘连与安全验收前，物理上不安装执行器。

### 12.2 四个刚性前置条件

1. **场所确认**：无真实宿舍许可时，在批准的实验室封闭设施做**有限组合验证**；桌面回路不能称与真实宿舍 $100\%$ 等效（负载、线路、噪声、长时变化与行为有差异），推广另需许可与现场测试。

### 13.3 五条最终原则

1. 先把测量链路与数学定义写到自洽，再谈算法创新。
2. 每个数字要么有手册/条款/推导支撑，要么标〔待测〕。
3. 每项能力要么有实测，要么写“设计目标/待验证假设（附退路）”。
4. 计划写成计划，结果写成结果。
5. 宁可少承诺一项，绝不在省赛交不出可复现数据。

## 附录 C 答辩追问（12 组）

1. **限电误伤有统计吗？** 定性机制明确，媒体有具体案例（B 级），全国定量误伤率无官方统计；申报前补本校问卷/访谈。访谈只说明感受，不能反推误伤率。
2. **为什么不装智能插座？** 比较的是支路单点与逐插孔测量的安装/管理取舍。支路监测覆盖经现场确认的同一回路，但不能说学生无法绕开，也不代表照明、空调都被覆盖。
3. **NILM 成熟，你们研究什么？** 不把相量相减当新发明；研究单宿舍受限场景下的低成本事件辨识、质量门控与可复核记录；先验证基线，再用公平对照判断增强是否形成差异化。
4. **只测单间、样本少够吗？** 校赛不做统计推断；省赛前每台重复启停 $15\sim20$ 次，用于验证单支路可分性与端到端链路，不宣称全国泛化；样本不足就缩小结论。
5. **背景大功率波动怎么办？** 属动态背景漂移，在 6.4 做质量门控：查前后窗口功率方差、谐波方差与电压变化；不确定则保存并输出“无法确定/混合”，不强行单标签；标量与暂态也可能失效。
6. **LM358 相移未公开，相位可信吗？** 先核验模块与工作范围，再做全链路幅相测试；电水壶只做基波一致性，高次由 E1 逐频点标定并报残差；只补偿稳定可测的系统误差，不承诺一次校准全消除。
7. **怎么通知管理员？** 首版用授权局域网 Web 看板与 WebSocket；外部通道非必需，企业微信/钉钉 Webhook 常涉外部服务，未核验流向与治理前不算局域网方案；延迟为待测目标。
8. **为什么不用 CNN/LSTM？** 数据少、范围有限，复杂模型过拟合与调参风险高，首版用可复现、可解释基线；分类在主机跑，**不能以 F103 无 FPU 证明主机不能用深度学习**——是没必要，不是不可能。
9. **相量差也受背景影响，还有什么价值？** 它在同一相位坐标下比较前后谐波，比直接相减比值更接近新增变化；但不是精确剥离，必须配质量门控；公平对照无增益就按 H1 停用。
10. **单周期 Hann 有问题，为什么不用多周期？** 多周期会改频点索引、相干增益与频偏误差，需重定义整套提取；首版先用矩形窗＋整周期把公式与库实现对清，超目标再上同步跟踪。
11. **校赛为什么不赶 Demo？** 校赛不要求 Demo；优先把接口、特征、协议与状态口径做实，不用未标定数据制造完成印象；仓促样机在答辩现场跳变反而损害可信度。没有 Demo 不是技术已成立的证据。
12. **竞品内部算法你怎么知道？** 不知道，也不推断；只比较准确型号的公开手册、接口与可获得记录；未公开波形不证明不能输出；自身证据功能是设计目标，实现与价值分别验证。
